① 編集モード

Tab で、オブジェクトモード ⇄ 編集モード

入る ／ 出るモノを選んで Tab（ヘッダー左の「オブジェクトモード ▾」→ 編集モード でも）
見分け方ヘッダー左が「編集モード」／ 点と線が見える ／ ツールバーの道具が増える
G／R／S・Cmd ＋ Z編集モードでも同じ。選んだ部分だけが動く
注意編集モードのまま Shift ＋ A すると、同じモノの中に足される → 別のモノは Tab で出てから足す
① 頂点・辺・面を選ぶ

ヘッダーの 3 つのボタンで「何を選ぶか」を決める

Tab ＝ オブジェクトモード ⇄ 編集モード
頂点 ／ 辺 ／ 面 を選ぶモード
今日使うメニュー：頂点・辺・面
切り替えヘッダーの 3 つのアイコン（1／2／3 は視点になる：テンキーを模倣が ON のため）
選ぶ ／ 追加 ／ 全部 ／ 解除クリック ／ Shift ＋ クリック ／ A ／ Option ＋ A（第6回と同じ）
ぐるっと一周（ループ選択）辺をダブルクリック（選択 → 選択ループ → 辺ループ でも）
裏側も選ぶ透過表示（Option ＋ Z）にすると、裏の点も見えて選べる
② 押し出し

E ― 選んだ面が「生えて」くる

1 面を選ぶ面選択モード → 面をクリック
2 E → 指を動かす → クリック面の向きにまっすぐ伸びる（引っこめると へこむ）
数値でE → 0.5 → ⏎（1 ＝ 1 m。マイナスで へこむ）
ツールバーで押し出し（領域）→ 黄色い ＋ をドラッグ
メニューで面 → 面を押し出し
やめる右クリック・Esc → 面が同じ場所に重なって残る → Cmd ＋ Z で戻す

動画（20 秒）：面をクリック → E → 指を上へ → クリックで確定。ツールバーの 押し出し（領域）→ ＋ をドラッグ でも同じ

② ループカット

Cmd ＋ R ― ぐるっと一周、辺を増やす

1 Cmd ＋ R → 辺の上にマウス黄色い線が一周出る（マウスを置いた辺を またぐ向き）
2 クリック → 位置を決めて クリック右クリックで真ん中に
本数を変える左下の「ループカットとスライド」を開く → 分割数（クリック前なら 2本指で上下スクロールでも）
ツールバーでループカット → 辺の上でクリック
メニューで辺 → ループカットとスライド
何のため？面を分けて、一部だけ押し出す・ふくらませる ための下ごしらえ

動画（23 秒）：Cmd ＋ R → 辺の上 → 黄色い線 → クリック → 右クリック → 左下のパネルで 分割数 7。ツールバーの ループカット → 辺をクリック でも同じ

左下の「▸ ループカットとスライド」をクリックで開く → 分割数 を変える

② 面の差し込み

I ― 面の内側に、ひとまわり小さい面を作る

1 面を選ぶ面選択モード → 面をクリック
2 I → 指を内側へ → クリック小さい面と、まわりの「ふち」ができる
数値でI → 0.2 → ⏎
組み合わせI のあと E で へこませる ＝ 太鼓の打面・スピーカー・コップ
ツールバーで面を差し込む → 黄色い輪をドラッグ
メニューで面 → 面を差し込む

動画（20 秒）：面をクリック → I → 指を内側へ → クリックで確定。ツールバーの 面を差し込む → 輪をドラッグ でも同じ

② ベベル

Cmd ＋ B ― 角を落として、丸くする

1 辺を選ぶ辺選択モード → 辺をクリック（全部なら A）
2 Cmd ＋ B → 指を動かして幅 → クリック角が斜めに落ちる
丸くする左下の「ベベル」→ セグメント を 3〜5（クリック前なら 2本指スクロールでも）
ツールバーでベベル → 黄色い輪をドラッグ
メニューで辺 → 辺をベベル
コツ幅が大きすぎると形が崩れる → Cmd ＋ Z で戻して小さく

動画（22 秒）：辺をクリック → Cmd ＋ B → 指を動かす → クリックで確定 → 左下の セグメント。ツールバーの ベベル → 輪をドラッグ でも同じ

つまずきやすいポイント

何も起きない編集モードに入っている？（ヘッダー左が「編集モード」）／ マウスは 3D ビューポートの上 ／ 入力を英数に
面が選べないヘッダーの 面 アイコン（面選択モード）にする
1／2／3 で視点が変わるテンキーを模倣が ON のため。頂点・辺・面はヘッダーのアイコンで
押し出しをやめたら面が重なったCmd ＋ Z（Esc・右クリックだけでは、同じ場所に面が残る）
Cmd ＋ R で黄色い線が出ない辺の真上にマウスを置く（面の上では出ない）
裏側の点が選べない透過表示（Option ＋ Z）にする
足したモノが くっついて 1 つになった編集モード中の Shift ＋ A は同じモノに入る → Tab で出てから足す
形が崩れたCmd ＋ Z で戻る（何回でも）。うまくいったら Cmd ＋ S
今日のまとめ

第7回のまとめ

  • Tab：オブジェクトモード ⇄ 編集モード。ヘッダーのアイコンで 頂点・辺・面
  • E 押し出し ／ Cmd ＋ R ループカット ／ I 面の差し込み ／ Cmd ＋ B ベベル
  • 左下の「最後の操作を調整」で 分割数・セグメント。やりすぎたら Cmd ＋ Z
  • 作る順番：ループカットで分ける → 面を選ぶ → 押し出す・差し込む
  • 課題：1 つのプリミティブから「音の出るモノ」（E と Cmd ＋ R を使う）→ スクショを提出

次回：第8回 モディファイア・色 ― ミラーで左右対称、サブディビジョンサーフェスでなめらか、マテリアルで色。Blender はここまで。今日の .blend は消さない。
