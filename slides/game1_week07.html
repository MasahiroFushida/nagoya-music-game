Section 01

物理エンジンの基本

Rigidbody と Collider ― 当たり判定の 2 本柱

Rigidbody / Collider

2 つのコンポーネントの役割

Rigidbody

  • 物理演算（重力・速度・力）を有効にする
  • 主なプロパティ：Mass / Drag / Use Gravity / Is Kinematic
  • 動かしたい物体に付ける

Collider

  • 「当たり判定の形」を決める
  • Box / Sphere / Capsule / Mesh など
  • Is Trigger ON で物理衝突せず侵入のみ検知

衝突イベント（OnCollisionEnter / OnTriggerEnter）が呼ばれるには、衝突する 2 つのうち 少なくとも一方に Rigidbody が必要。

概念図

Rigidbody × Collider の組み合わせ

OnCollisionEnter

衝突を検知する 3 つのメソッド

using UnityEngine; public class Sample : MonoBehaviour { // 衝突した瞬間に 1 回だけ呼ばれる void OnCollisionEnter(Collision collision) { } // 衝突している間、毎フレーム呼ばれる void OnCollisionStay(Collision collision) { } // 離れた瞬間に 1 回だけ呼ばれる void OnCollisionExit(Collision collision) { } }
引数の型は Collision。トリガーの Collider と混同しないこと。
概念図

Enter / Stay / Exit のタイミング

同じ OnCollisionEnter 系でも「瞬間（1回）」「接触中（毎フレーム）」「離れた瞬間（1回）」と呼ばれ方が違う

概念図

Stage5-1 を上から見た図

真上から見たレイアウト ― Player が Tama を発射し、奥に置かれた Enemy に当てる構成
Player.cs（Stage5-1）

左右移動 + Space で Tama を撃つ

using UnityEngine; public class Player : MonoBehaviour { public GameObject tama; // Inspector で Tama Prefab を割り当てる void Update() { if (Input.GetKeyDown(KeyCode.RightArrow)) transform.position += Vector3.right; if (Input.GetKeyDown(KeyCode.LeftArrow)) transform.position += Vector3.left; if (Input.GetKeyDown(KeyCode.Space)) Instantiate(tama, transform.position + Vector3.forward, Quaternion.identity); } }
Tama.cs / Enemy.cs（Stage5-1）

衝突した瞬間に自分を消す

// === Tama.cs === public class Tama : MonoBehaviour { void Update() { transform.Translate(Vector3.forward * 0.1f); // 前進 } void OnCollisionEnter(Collision collision) { Destroy(gameObject); // 何かに当たったら自分を消す } } // === Enemy.cs === public class Enemy : MonoBehaviour { private void OnCollisionEnter(Collision collision) { Destroy(gameObject); // 当たったら消える } }

Tama も Enemy も「自分の OnCollisionEnter で自分を Destroy」。これで当たった瞬間に両方消える。

Section 03

動く敵（Stage5-3）

Enemy_5_3.cs ― public 変数で速度を Inspector から調整する

Enemy_5_3.cs（Stage5-3）

敵が手前に向かって近づいてくる

using UnityEngine; public class Enemy_5_3 : MonoBehaviour { public float enemySpeed; // 敵の移動速度（Inspector で設定） void Update() { transform.Translate(Vector3.back * enemySpeed); // 毎フレーム手前に進む } private void OnCollisionEnter(Collision collision) { Destroy(gameObject); // 何かに当たったら消える } }
public float にすると Inspector に「Enemy Speed」欄が出る。

Section 04

壁と Static Collider（Stage5-4〜5-6）

Rigidbody なし＝動かない当たり判定（壁・床）

Static Collider

動かないオブジェクトの当たり判定

Rigidbody を付けず Collider だけのオブジェクトは「動かない物体」として扱われる。地面・壁・障害物に使う。

A
Stage5-4Player のみのシンプル構成で動作確認。プレイヤーが Plane の上を移動するだけ。
B
Stage5-5Cube を 4 つ並べて並べて障害物として配置。Tama が Cube に当たって消えるか確認する。
C
Stage5-6Cube を細長く変形して「Wall」「Wall2」「Wall3」「Wall4」と命名。ステージの枠を作る。

Wall には Rigidbody を付けないこと。重力で落下せず、Collider だけが残って動かない壁になる。

Tag の作成

Tag を作って割り当てる手順

2
+ ボタンで新規 Tag を追加今回は「Tama」と「Player」を作成

Enemy_5_8.cs（Stage5-8・5-9）

Tama に当たったときだけスコアを加算

using UnityEngine; public class Enemy_5_8 : MonoBehaviour { public float enemySpeed; public GameManager gameManager; // Inspector で割り当てる void Update() { transform.Translate(Vector3.back * enemySpeed); } private void OnCollisionEnter(Collision collision) { if (collision.gameObject.tag == "Tama") // Tama タグに当たったときだけ { gameManager.score++; // スコアを 1 点加算 Destroy(gameObject); } } }

これで「壁にぶつかっても消えない／Tama に当たったときだけ消えてスコア +1」が実現する。

Section 06

Player の体力管理（Stage5-10）

Player_5_10.cs ― 衝突した相手のタグを見て HP を減らす

Player_5_10.cs（Stage5-10）

衝突したら HP を 1 減らす

using UnityEngine; public class Player_5_10 : MonoBehaviour { public GameObject tama; public GameManager gameManager; void Update() { if (Input.GetKeyDown(KeyCode.RightArrow)) transform.position += Vector3.right; if (Input.GetKeyDown(KeyCode.LeftArrow)) transform.position += Vector3.left; if (Input.GetKeyDown(KeyCode.Space)) Instantiate(tama, transform.position + Vector3.forward, Quaternion.identity); } void OnCollisionEnter(Collision collision) { Debug.Log("衝突したオブジェクトのタグ : " + collision.gameObject.tag); gameManager.playerHitPoint--; // プレイヤーの体力を 1 減算 } }

このままだと「壁に触れても HP が減る」状態。
応用：if (collision.gameObject.tag == "Enemy") で敵だけに反応させてみよう。

発展：Is Trigger

衝突判定 vs トリガー判定

衝突（Collision）

  • 物理的に押しのけ合う
  • 壁・敵・弾の基本挙動
  • イベント：OnCollisionEnter
  • 引数型：Collision

→ Is Trigger は OFF

トリガー（Trigger）

  • すり抜けて侵入だけ検知
  • アイテム取得・ゴール・ダメージ範囲
  • イベント：OnTriggerEnter
  • 引数型：Collider

→ Is Trigger は ON

判断基準：「物理的にぶつかってほしいか？」
ぶつかってほしい → Collision、すり抜けさせたい → Trigger。

まとめ

今日学んだこと
