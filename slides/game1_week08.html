Section 01

AudioSource の基本

音を鳴らすための 2 つの部品 ― AudioClip と AudioSource

AudioSource / AudioClip

音を鳴らす 2 つの部品

AudioClip

  • 音声ファイル本体（.mp3 / .wav など）
  • Assets/Audio フォルダに入れて使う
  • 例：ジャンプ.mp3 / hiphop2.mp3

AudioSource

  • 「音を鳴らす装置」のコンポーネント
  • GameObject に Add Component で追加
  • AudioClip 欄に鳴らしたい音をドラッグ

音を聞くには AudioListener も必要。新規シーンの Main Camera に最初から付いているので、特に設定する必要はない。

Player.cs

スペースキーで AddForce ＋ audioSource.Play()。
Player にアタッチ。

Player の AudioSource は Play On Awake を OFF。シーン開始時に勝手に鳴ってほしくないので、スクリプトから Play() で鳴らす。
Player.cs（Stage6-1）

ジャンプ + 効果音再生

using UnityEngine; public class Player : MonoBehaviour { private Rigidbody playerRb; private AudioSource audioSource; void Start() { playerRb = GetComponent<Rigidbody>(); audioSource = GetComponent<AudioSource>(); } void Update() { // スペースキーが押されたら、 if (Input.GetKeyDown(KeyCode.Space)) { playerRb.AddForce(Vector3.up * 400); // 上方向に力 audioSource.Play(); // ジャンプ音を鳴らす } } }

GetComponent<AudioSource>() で「自分自身に付いている AudioSource」を取得し、Play() で鳴らす。

Section 03

BGM を流す（Stage6-2・6-3）

Play On Awake と Loop でずっと鳴り続ける音楽

Stage6-2・6-3

BGM 用の空オブジェクトを作る

1
Hierarchy で右クリック → Create Empty名前を「BGM」に変更し、Position は 0,0,0。
2
BGM に AudioSource を追加Add Component → Audio → AudioSource。
3
AudioClip 欄に hiphop2.mp3 をドラッグAssets/Audio からドラッグ＆ドロップ。
4
Play On Awake と Loop を ONシーン開始と同時に再生され、終わったら最初に戻ってずっと鳴り続ける。
BGM はスクリプト不要。AudioSource の設定だけで勝手に流れる。
AudioSource の設定

Play On Awake と Loop

Play On Awake

  • シーン開始時に自動で再生する
  • ON：BGM 向き（自動再生）
  • OFF：効果音向き（自分で Play() を呼ぶ）

Loop

  • 音が終わったら最初に戻って繰り返す
  • ON：BGM 向き
  • OFF：効果音向き（1 回だけ鳴る）

BGM ＝ Play On Awake ON + Loop ON
効果音（SE） ＝ Play On Awake OFF + Loop OFF

概念図

BGM と 効果音(SE) の役割分担

BGM は「設定だけで自動再生」、SE は「スクリプトから Play() で呼び出す」のが基本パターン
Section 04

動きを加える（Stage6-4）

Player_6_4.cs ― 左右移動 + ジャンプ + 効果音

Player_6_4.cs（Stage6-4）

矢印キーで左右移動を追加

using UnityEngine; public class Player_6_4 : MonoBehaviour { private Rigidbody playerRb; private AudioSource audioSource; void Start() { playerRb = GetComponent<Rigidbody>(); audioSource = GetComponent<AudioSource>(); } void Update() { if (Input.GetKeyDown(KeyCode.Space)) { playerRb.AddForce(Vector3.up * 400); audioSource.Play(); } if (Input.GetKeyDown(KeyCode.RightArrow)) transform.Translate(Vector3.right); if (Input.GetKeyDown(KeyCode.LeftArrow)) transform.Translate(Vector3.left); } }
Stage6-4 では BGM オブジェクトも置いたまま。BGM ＋ ジャンプ音 ＋ 左右移動が同時に動く、「ゲームらしい」状態になる。
Section 05

時間で物を生成する

Stage6-5・6-6・6-7 ― Instantiate と タイマー の組み合わせ

SpawnManager.cs（Stage6-5）

Start() で Cube を 1 個だけ生成する

using UnityEngine; public class SpawnManager : MonoBehaviour { public GameObject cube; // Inspector で Cube Prefab を割り当てる private float posX; private float posZ; private Vector3 randomPos; void Start() { // -10 〜 10 のランダムな値 posX = Random.Range(-10, 10); posZ = Random.Range(-10, 10); randomPos = new Vector3(posX, 0.5f, posZ); // cube を randomPos の位置に生成 Instantiate(cube, randomPos, Quaternion.identity); } }

空オブジェクト「SpawnManager」を作ってこのスクリプトをアタッチし、Inspector の cube 欄に Cube Prefab をドラッグする。

Stage6-6

タイマー機能を作る（Time.deltaTime）

public class SpawnManager_6_6 : MonoBehaviour { public GameObject cube; private float timer; private float timeLimit = 1.0f; // 1 秒ごとに反応 void Update() { // 前のフレームからの経過時間を足していく timer += Time.deltaTime; if (timer > timeLimit) { timer = 0; // タイマーをリセット Debug.Log("1秒経過"); } } }
まずは Debug.Log で 「本当に 1 秒ごとに呼ばれているか」 を Console で確認するのがコツ。
概念図

Time.deltaTime とタイマーの仕組み

SpawnManager_6_7.cs（Stage6-7）

1 秒ごとに Cube を生成する

public class SpawnManager_6_7 : MonoBehaviour { public GameObject cube; private float posX; private float posZ; private Vector3 randomPos; private float timer; private float timeLimit = 1.0f; void Update() { timer += Time.deltaTime; if (timer > timeLimit) { timer = 0; posX = Random.Range(-10, 10); posZ = Random.Range(-10, 10); randomPos = new Vector3(posX, 0.5f, posZ); Instantiate(cube, randomPos, Quaternion.identity); } } }

「Stage6-5（1 回だけ生成）」と「Stage6-6（タイマー）」を組み合わせると 1 秒ごとにランダム位置に Cube を生成するゲームの土台ができあがる。

Bonus

ゲームアート

音と映像と操作が一体になった表現としてのゲーム

ゲームアートとは

音と映像で「体験」をつくる芸術

ゲームは「ルールがあるから面白い」だけでなく、音と映像と操作が一体となって感情を動かす芸術表現でもある。特に音楽と映像の連動は近年のゲーム表現の中心テーマのひとつ。

  • サウンドトラックが「アルバム作品」として独立して評価される時代に
  • 映像と音が連動して共感覚（シナスタジア）的な体験を作る
  • 個人・少人数のインディーゲームでも質の高い音楽表現が可能
  • 音大生が関わる分野として「ゲーム音楽」「サウンドデザイン」が拡大中

次のスライドで、音と映像の連動が特に印象的な代表作をいくつか紹介する。

代表的な作品

音と映像が一体化したゲーム

2001 / 2016 (Infinite)

Rez Infinite

水口哲也（United Game Artists / Enhance）

thatgamecompany ／ 音楽：Austin Wintory

セリフのない約 2 時間の旅。サウンドトラックはゲーム史上初めてグラミー賞にノミネートされた金字塔。
2018

Tetris Effect

水口哲也（Enhance / Monstars）

テトリスのブロック操作のすべてが音楽演奏になる。プレイ全体が壮大な音と映像のショーに変わる。
2018

Gris

Nomada Studio ／ 音楽：Berlinist

水彩画のような映像と、ピアノ・弦楽のアンビエントが絡みあう、喪失と再生をテーマにした美しい作品。
2019

Sayonara Wild Hearts

Simogo

「遊べるポップアルバム」。1 曲が 1 ステージになっていて、音楽そのものがゲームのリズム・展開を決める。
2017

Cuphead

Studio MDHR

1930 年代のアニメーションをそのまま再現した映像 ＋ 生演奏のジャズ・ラグタイム。アートと音楽の手仕事の極致。
これらは「音が後付けでなく、ゲームデザインそのものに音楽が組み込まれている」点が共通している。Unity でも、AudioSource をきっかけに同じ方向の表現に近づける。
ビデオアート

ゲームエンジンを使うアーティスト ― 谷口暁彦

ゲームアートの隣接領域として、ビデオアート（映像作品としての現代アート）がある。今、ゲームエンジンはゲームを作るだけの道具ではなく、現代美術の表現手段としても使われている。

谷口暁彦（たにぐち あきひこ）

メディアアーティスト ／ 多摩美術大学 情報デザイン学科 メディア芸術コース。
1983 年生まれ。インターネット・アート、3DCG、ビデオアートを横断する作品を発表。
