授業概要

秋学期で何を作るか

ゲーム2とは

Blender で作って、AR で置く

春学期は、画面の中で「操作 → 音」の作品を作りました。秋学期は、その音を現実の空間に置きます。

🧊
Blender で作る 楽器・小物など、置きたいモノを自分でモデリング
→
📱
AR で置く スマホをかざすと、机や床の上にそのモノがある
→
🔊
触れると鳴る タップすると音が鳴る。「操作 → 音」の AR 版

秋学期のゴール：自分でモデリングしたモノを現実の空間に置いて、触れると音が鳴る AR 作品を1人1つ作る（第15回に発表）。

AR とは

AR（拡張現実）＝ 現実の空間に、デジタルなモノを重ねる

どういう技術？

  • スマホのカメラで床・机などの面を認識する（平面検出）
  • スマホを動かしても、置いたモノがその場所にとどまる（トラッキング）
  • 3D オブジェクトも、音も置ける

身近な例

  • ポケモン GO（Unity 製）
  • IKEA Place（家具を部屋に置いて試す）
  • iPhone の「計測」アプリ
  • Google マップのライブビュー（矢印を道に重ねる）

Unity では AR Foundation という仕組みを使うと、iPhone（ARKit）と Android（ARCore）の両方に同じプロジェクトで対応できます。春学期に配った AR テンプレートが、まさにこれです。

Blender とは

無料で使える、本格的な 3DCG ソフト

Blender でできること

  • モデリング（形を作る）・マテリアル（色や質感をつける）
  • アニメーション・レンダリング（絵として書き出す）
  • 映画・ゲーム・VTuber のモデルなど、幅広く使われている
  • 無料・オープンソース。Mac / Windows どちらでも動く
  • 公式サイト：blender.org　ダウンロード：blender.org/download

この授業で使う範囲

  • モデリングと色づけだけ（第6〜9回）
  • プリミティブの組み合わせ → 押し出し → モディファイア → 色
  • 作ったモデルを FBX で書き出して Unity に持っていく
  • アニメーションや UV 展開はやらない

Unity にも形はありますが（Cube・Sphere…）、「自分で作ったモノを置く」ことで作品になります。Blender はそのための道具です。インストールは第6回の授業内で行います（今日は入れなくて OK）。

やってみよう

ARテンプレートを動かす

ARテンプレート（game1_template_ar）

春学期第12回で配ったテンプレートが、秋学期の入り口

何が入っている？

  • カメラで床・机を認識して面を表示（平面検出）
  • 目の前に浮かぶ赤いキューブをタップすると落ち、着地すると音が鳴る（「操作 → 音」のAR版）
  • 第1回で使うのはここまで。ほかの機能はこの先の回で少しずつ
  • iPhone / Android 両対応

環境

  • Unity 2022.3.62f3（春学期と同じ）
  • AR Foundation 5.2.2
  • XR Simulation（仮想の部屋）同梱
  • 授業ページの「Unityプロジェクト（配布ファイル）」からダウンロード

秋学期はこのテンプレートを少しずつ改造していきます。第3回で「置くモノ」を差し替え、第10回でそれを自作モデルにします。

手順

ARテンプレートを Unity で開く

1
ダウンロードして解凍する授業ページ 第1回 → 「ARテンプレート（game1_template_ar）」の zip をダウンロード → ダブルクリックで解凍。フォルダは日本語やスペースを含まない場所（例：ユーザ/自分の名前/Unity/）に置く
2
Unity Hub に追加するUnity Hub → プロジェクト → 「追加」→ 解凍したフォルダ（game1_template_ar-main）を選ぶ
3
2022.3.62f3 で開くバージョンの欄が 2022.3.62f3 になっていることを確認してクリック。初回は数分かかります（パッケージの取り込み）
4
ARScene を開いて PlayProject ウィンドウ → Assets/Scenes/ARScene をダブルクリック → ▶ Play。Game ビューに仮想の部屋が出れば成功
XR Simulation

仮想の部屋の歩き方（Play 中の操作）

キー・マウス動作実機ではこれ
W / A / S / D前後左右に移動歩く
Q / E下降 / 上昇しゃがむ・背伸び
← → ↑ ↓視点を回すスマホの向きを変える
左 Shift ＋ 移動キー3倍速で移動―
キューブを短くクリックキューブが落ちる（着地で音）タップ

Play すると目の前に赤いキューブが浮かんでいます。まず部屋の中を少し歩き回って、床に半透明の面が出るのを確認 → キューブを短くクリックして落としてみましょう。音が鳴ったら OK（音量を確認）。

うまくいかないとき

つまずきやすいポイント

  • バージョンを聞かれる／別のバージョンで開いた → 必ず 2022.3.62f3 で開く。ない人は Unity Hub → インストール → 2022.3.62f3 を追加
  • 開くのに時間がかかる → 初回は普通です。5〜10分待つ。途中で閉じない
  • Play しても真っ暗・何も出ない → Window → XR → AR Foundation → XR Environment を開き、環境（部屋）が選ばれているか確認
  • 面が出ない → 少し歩き回る・視点を床に向ける。平面検出には数秒かかります
  • クリックしても落ちない → 短くクリック。押したままにすると「掴む」モードになり落ちません
  • キューブが落ちて消えた／見当たらない → 面が出る前に落とすと床を突き抜けますが、1〜2秒で目の前に出直します。歩き回って見失ったら矢印キーで視点を回して探す
  • 音が鳴らない → Mac の音量、Game ビュー右上の Mute Audio が ON になっていないか
  • Console に赤いエラー → そのまま先生を呼んでください
宿題（任意）

スマホ実機ビルドの準備

なぜ今から準備するのか

実機ビルドをします。

📱 iPhone の人 → Xcode

  • Unity で書き出した iPhone アプリは、Xcode という Apple のアプリを通してスマホに入れる
  • Xcode は第2回の授業で配布します（App Store から入れなくてOK）。空き容量は 25GB ほど必要なので、今のうちに整理しておく
  • Apple ID があれば OK（有料の Developer Program は不要）

🤖 Android の人 → Android Build Support

  • Unity Hub から Android 用のモジュールを追加する
  • OpenJDK・Android SDK & NDK Tools を含めて 数 GB
  • スマホ側の設定（USB デバッグ）は第2回に一緒にやります
どちらも任意です。「実機で動かしてみたい」人だけ、次回までに家の Wi-Fi で進めておいてください。できなくても第4回に一緒にやりますし、その後の授業は仮想の部屋で進められます。
iPhone の人

Xcode の準備（配布は第2回）

1
空き容量を確認するりんごマーク → 「この Mac について」→ ストレージ。25GB 以上空いていない場合は、不要なファイルを整理しておく（これが今回やること）
2
macOS のバージョンを控えておく同じ「この Mac について」に出ています。第2回に、そのバージョンに合う Xcode のファイルを配ります
3
インストールは第2回の授業で配布ファイル（.xip）から入れるので、App Store からダウンロードする必要はありません（すでに入れた人はそのままで OK）。第2回の授業ページにダウンロードリンクも載せます
App Store の最新 Xcode は新しい macOS（26.6 以降）と Apple シリコン Mac が必要で、入れられない人が出ます。そのため授業で配る Xcode を使います。iPhone の iOS は、実機ビルドが終わるまでアップデートしないでください（Xcode より新しい iOS は扱えません）。
Android の人

Android Build Support の追加

1
Unity Hub → インストール左のメニューから「インストール」を開き、2022.3.62f3 の右上の歯車 ⚙ → 「モジュールを加える」
2
3つにチェックを入れる「Android Build Support」を開いて、Android Build Support・OpenJDK・Android SDK & NDK Tools の3つすべてにチェック
3
インストール「インストール」→ ライセンスに同意。数 GB のダウンロードなので Wi-Fi で
4
確認ARテンプレートを開き、File → Build Settings → Platform の一覧に Android があり、「No Android module loaded」と出なければ OK（Switch Platform はまだ押さない）
