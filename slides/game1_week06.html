Section 01

UIとは

User Interface ― プレイヤーとゲームをつなぐ情報窓口

UI とは

UI（ユーザーインターフェース）

プレイヤーがゲームの状態を把握し、操作するための視覚的な要素の総称。

表示系UI

  • スコア表示
  • 体力バー（HP）
  • 残り時間・残機数
  • メッセージ表示

操作系UI

  • スタートボタン
  • ポーズメニュー
  • 設定画面
  • ゲームオーバー画面

UIはゲームの「伝える力」。情報が伝わらないと、どんなに面白いゲームでもプレイヤーが混乱する。

Canvas

CanvasはUIの土台

UnityではすべてのUI要素は Canvas の子オブジェクトとして配置する。

1
Canvasオブジェクト画面全体を覆う「透明な板」。UI要素を描画する専用レイヤー。
2
EventSystemCanvasと同時に自動生成される。ボタンのクリックなどのイベントを管理する。
3
Render Mode通常は「Screen Space - Overlay」を使用。常に画面の最前面に表示される。
Section 02

Legacy Text を配置する（stag4-1）

まずは昔ながらの Text コンポーネントで基本を押さえる

Text 配置

Hierarchy → UI → Text - Legacy

1
Hierarchy を右クリックUI → Text - Legacy を選択
2
Canvas と EventSystem が自動生成されるText オブジェクトは Canvas の子になる
3
Inspector で表示内容を設定Text 欄に文字列・色・サイズ・揃え方を指定
4
Scene ビューで位置を調整Rect Transform の Anchor で画面端への固定が可能
⚠ オブジェクト名はデフォルトの「Text (Legacy)」のままにしておくと、後で GameObject.Find から探しやすい。
Text コンポーネント

Inspector の主要プロパティ

Text セクション

  • Text：表示する文字列
  • Font：使用するフォント（Arial など）
  • Font Size：文字の大きさ
  • Alignment：左・中央・右揃え
  • Color：文字色

Rect Transform

  • Anchor：基準点（左上・中央など）
  • Pos X / Y：Canvas 上の位置
  • Width / Height：テキスト領域のサイズ
  • Anchor Presets で画面端への固定が簡単

Legacy Text のスクリプト操作には using UnityEngine.UI; の宣言が必須。

Section 03

スクリプトから Text を操作

stag4-2：Inspector で紐づける方法

Test4_2.cs（stag4-2）

① public 変数 + Inspector ドラッグ

using UnityEngine; using UnityEngine.UI; // UIを使用するための宣言 public class Test4_2 : MonoBehaviour { public Text myText; // Textコンポーネントを格納する変数 void Update() { if (Input.GetKeyDown(KeyCode.Space)) { myText.text = "スペースキーが押されました！"; } } }

myText は public なので Inspector に「My Text」欄が現れる。そこに Hierarchy の Text (Legacy) をドラッグして紐づける。

Section 04

GameObject.Find で取得（stag4-3）

コードからオブジェクトを名前で探す方法

Test4_3.cs（stag4-3）

② GameObject.Find で取得

using UnityEngine; using UnityEngine.UI; public class Test4_3 : MonoBehaviour { Text myText; // public でなくてもOK void Start() { // Hierarchyから「Text (Legacy)」という名前のオブジェクトを探す myText = GameObject.Find("Text (Legacy)").GetComponent<Text>(); } void Update() { if (Input.GetKeyDown(KeyCode.Space)) { myText.text = "スペースキーが押されました！"; } } }
⚠ Find の引数はオブジェクト名と完全一致させること。スペース・括弧も含めて正確に。
2つの方法の使い分け

Inspector 紐づけ vs GameObject.Find

① public + Inspector

  • 動作が高速・確実
  • 紐づけ忘れに気づきやすい
  • Inspector でリンク状態が見える
  • こちらが基本

② GameObject.Find

  • コードだけで完結する
  • 名前変更で簡単に壊れる
  • Find は処理が重いので Start で1回だけ
  • 動的に生成されたオブジェクトを探すときに便利

慣れるまでは ① public + Inspector を基本にする。Find はオブジェクトが多数あって Inspector 紐づけが大変なときの選択肢。

Section 05

スコア表示（stag4-4）

変数の値をリアルタイムに Text に反映する

Test4_4.cs（stag4-4）

Sキーでスコアを加算してUIに反映

using UnityEngine; using UnityEngine.UI; public class Test4_4 : MonoBehaviour { private int score; Text myText; Text scoreText; void Start() { myText = GameObject.Find("Text (Legacy)").GetComponent<Text>(); scoreText = GameObject.Find("Score").GetComponent<Text>(); } void Update() { if (Input.GetKeyDown(KeyCode.Space)) myText.text = "スペースキーが押されました！"; if (Input.GetKeyDown(KeyCode.S)) { score++; // スコアを1点加算 Debug.Log("Score: " + score); scoreText.text = "Score: " + score; // UIに反映 } } }
stag4-4 のシーン構成

必要なオブジェクトと名前

Canvas（自動生成）

子に Text (Legacy) と Score の2つの Text を配置。
位置は Anchor で画面端などに固定。

Text (Legacy)

メッセージ表示用。
Space キーで内容が書き換わる。

Score

スコア表示用の Text（名前を「Score」に変更）。
S キーを押すたびに数字が増える。

Cube（任意）

Test4_4.cs をアタッチする土台。
Cube でも EmptyObject でも可。

⚠ GameObject.Find("Score") で取得するので、Text オブジェクトの名前は必ず「Score」にする。
