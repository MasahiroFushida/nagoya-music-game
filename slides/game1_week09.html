Asset Store を体験する（Stage1）

無料素材をダウンロードしてシーンに置いてみる

素材は「自分で作る」だけじゃない

これまでは Cube や Sphere などの基本図形だけで作ってきた。Unity には世界中のクリエイターが公開している 3Dモデル・音・エフェクトの配布所「Asset Store」があり、無料のものも多い。今日はまず 素材を取得して使う体験をしてみよう。

今回の Stage1 で取得・体験する自然素材パック。
Stage1 の手順

Asset Store から素材を取得する

1
Asset Store を開くUnity の Window メニュー → Asset Store を選ぶ。今は「ブラウザで開く（Search online）」と案内されるので、そのボタンからブラウザで開く。直接 assetstore.unity.com を開いてもよい。
2
素材を探してログイン欲しい素材（例：Low Poly Simple Nature Pack）のページを開き、Unity ID でログインする。
3
「マイアセットに追加」→「Unity で開く」マイアセットに登録すると、自分の Unity から使えるようになる。
4
Unity で Window → Package Manager左上を「My Assets」に切り替え、登録した素材を選ぶ。
5
Download → Import確認ウィンドウで Import を押すと Assets フォルダに素材が追加される。
6
Prefab を Scene にドラッグ木や岩などの Prefab を Hierarchy / Scene に置いて、自分の世界を組み立ててみる。
Import すると Assets の中にたくさんファイルが増える。消したり場所を変えたりしないこと（モデルが表示されなくなる）。

Section 02

乗り物を動かす（Stage2）

Player.cs ― アクセルで前進、ハンドルで旋回

Stage2 のシーン構成

必要なオブジェクト

Plane（地面）

Y=0 に配置。
この上を乗り物が走る。

Player（Cube または 車）

Rigidbody を追加する。
Cube のままでもよいし、Simple Cars Pack の車に差し替えてもよい。

Player.cs

Player にアタッチ。
Inspector の Speed 欄で速さを調整できる（例：1.2）。

Main Camera

乗り物が見える位置に置く。
動きが追いやすい角度に調整する。

Simple Cars Pack（無料）

assetstore.unity.com … simple-cars-pack-97669

Stage2 で Player を差し替える車の素材パック。
前進には Rigidbody が必須。AddRelativeForce は「物理の力」なので、Rigidbody が無いと動かない。
Player.cs（Stage2）

前進と旋回のスクリプト

using UnityEngine; public class Player : MonoBehaviour { private Rigidbody playerRb; public float speed; // Inspector で速さを調整 void Start() { playerRb = GetComponent<Rigidbody>(); } void Update() { if (Input.GetKey(KeyCode.Space)) // スペースを押している間 playerRb.AddRelativeForce(Vector3.forward * speed); // 自分の前へ前進 if (Input.GetKey(KeyCode.RightArrow)) // → を押している間 transform.Rotate(0, 0.1f, 0); // 右に旋回 if (Input.GetKey(KeyCode.LeftArrow)) // ← を押している間 transform.Rotate(0, -0.1f, 0); // 左に旋回 } }

GetKeyDown（押した瞬間1回）ではなく GetKey（押している間ずっと）を使うので、押し続けるとアクセルのように加速していく。

Section 03

アニメーションの基礎（Stage3）

Animation ウィンドウとキーフレームで物を動かす

2つの部品

Animation Clip と Animator

Animation Clip（.anim）

  • 「動きの記録」そのもの
  • Animation ウィンドウで作る
  • 例：回転する／大きくなる／ジャンプする

Animator（コンポーネント）

  • 「どのアニメを再生するか」を管理する装置
  • Clip を作ると自動で付く
  • GameObject にアタッチされる

キーフレーム＝「この時間にこの状態」という目印。Unity が目印と目印の間を自動でなめらかにつないで動かしてくれる。

概念図

キーフレームの仕組み

Stage3 の手順

Cube を回す・大きくする

1
Cube を選択 → Window → Animation → AnimationAnimation ウィンドウを開く。
2
Create を押してクリップを保存名前を「Cube1」「Cube2」などにして保存（Animator が自動で付く）。
3
録画ボタン（●）を押す赤くなっている間の操作がキーフレームとして記録される。
4
時間を進めて Inspector で値を変える0秒で元の状態、後の時間で Scale や Rotation を変えると自動でキーが打たれる。
5
録画を止めて Play で確認Stage3 では Cube1＝拡大縮小、Cube2＝回転をループ再生する。
ループさせたいときは、Project でクリップを選び Inspector の Loop Time にチェックを入れる。
Section 04

回転と拡大縮小（Stage4）

動かす「プロパティ」を変えて表現を増やす

Stage4

動かせるのは位置だけじゃない

CubeRotate（回転）

  • Rotation（向き）をキーフレームで変える
  • くるくる回る動き
  • 記録するプロパティ：Rotation

CubeScale（拡大縮小）

  • Scale（大きさ）をキーフレームで変える
  • ふくらむ・しぼむ動き
  • 記録するプロパティ：Scale

Animation で動かせるのは Position（位置）・Rotation（向き）・Scale（大きさ）の3つが基本。さらに色やコンポーネントの値も動かせる。組み合わせると豊かな表現になる。

Section 05

Animator で状態を切り替える（Stage5）

ふだんは Idle、スペースで Jump ― 状態遷移とトリガー

Animator Controller

アニメの「切り替え地図」をつくる

1つのオブジェクトに複数のアニメ（待機・ジャンプなど）があるとき、「いつ・どのアニメに切り替えるか」を決めるのが Animator Controller。状態（State）と矢印（Transition）で地図のように組み立てる。

State（状態）

1つ1つのアニメ。
Stage5 では CubeIdle（待機）と CubeJump（ジャンプ）。

Transition（矢印）＋ Parameter

状態と状態をつなぐ矢印。
JumpTrigger という合図（Trigger）が来たら Idle → Jump へ移る。

概念図

Idle ↔ Jump の状態遷移

CubeJump.cs（Stage5）

スクリプトからアニメを再生する

using UnityEngine; public class CubeJump : MonoBehaviour { private Animator cubeAnim; void Start() { cubeAnim = GetComponent<Animator>(); // 自分の Animator を取得 } void Update() { if (Input.GetKeyDown(KeyCode.Space)) // スペースを押した瞬間 { cubeAnim.SetTrigger("JumpTrigger"); // 合図を送ってJumpへ切り替え } } }
"JumpTrigger" の文字は、Animator で作った Parameter の名前と完全に同じにすること（大文字・小文字も一致）。違うと反応しない。

まとめ

今日学んだこと

  • Asset Store：無料・有料の素材を取得し、My Assets → Package Manager で導入できる
  • AddRelativeForce：自分の向きに合わせて前進する（乗り物向き）
  • transform.Rotate：オブジェクトを旋回させる
  • Animation Clip：キーフレームで動きを記録する（Position / Rotation / Scale）
  • Animator：State と Transition でアニメの切り替えを管理する
  • SetTrigger：スクリプトから合図を送ってアニメを切り替える
