① モディファイア

元の形はそのまま、効果を「かぶせる」

開くプロパティの レンチ（モディファイアープロパティ）
足すモディファイアーを追加 → 生成 → ミラー ／ サブディビジョンサーフェス ／ 配列
直すパネルの数値を変えるだけ（元の形は残っている）
消すパネル右上の ×
順番上から順にかかる（∨ → 最初に移動 ／ 最後に移動）
確定する「適用」。ふつうはしない（Unity へは書き出し時に自動で適用される）
① ミラー

ミラー ― 半分作れば、左右対称

1 半分だけ作る原点（オレンジの点）が反転の中心
2 足すレンチ → モディファイアーを追加 → 生成 → ミラー
座標軸X ／ Y ／ Z ＝ どの向きに反転するか
ずらすときTab で編集モードにして動かす（オブジェクトモードで動かすと原点も動く）
クリッピング中心を越えないようにする（くっつけたまま編集）

動画（28 秒）：Tab → 右へずらす → Tab → レンチ → モディファイアーを追加 → 生成 → ミラー → 左にも出る

① サブディビジョンサーフェス

サブディビジョンサーフェス ― なめらかに丸く

1 足すレンチ → モディファイアーを追加 → 生成 → サブディビジョンサーフェス
ビューポートのレベル数1〜2 で十分（上げすぎると重い）
影もなめらかに右クリック → スムーズシェード（1 番上。「自動スムーズシェード」ではない）
角を残したい角の近くに Cmd ＋ R でループカットを足す
注意Cmd ＋ 1〜5 は「テンキーを模倣」が ON だと使えない → パネルで

動画（26 秒）：生成 → サブディビジョンサーフェス → ビューポートのレベル数 2 → 右クリック → スムーズシェード

① 配列

配列 ― 同じ形を、ずらりと並べる

1 足すレンチ → モディファイアーを追加 → 生成 → 配列
数いくつ並べるか
オフセット X間隔（1 ＝ ぴったり、1.3 ＝ すき間あり）。Y・Z にすると向きが変わる
4.5 の人「係数 X」（同じ意味）
5.2 の「配列（旧）」昔からの配列。どちらでも同じように並ぶ

動画（38 秒）：生成 → 配列 → 数 5 → オフセット X 1.3 → Y に変えると向きが変わる

② マテリアル

マテリアル ― 色をつける（第6回の復習 ＋ 2 色に分ける）

1 つけるマテリアルタブ（赤い玉）→ 新規 → ベースカラー をクリック → 色相環で選ぶ
2 見る3D ビューポート右上の マテリアルプレビュー（4 つの玉の 3 つ目）
別のモノに別の色そのモノを選んで → 新規
同じモノの一部だけTab → 面を選ぶ → スロットの ＋ → 新規 → 色 → 割り当て
名前名前欄をクリックして英数字で（Wood、Black など）

動画（48 秒）：カホンを 0 から。立方体 → S → Z → 1.5 → マテリアルタブ → 新規 → ベースカラー → マテリアルプレビュー → Tab → 面 → 前の面をクリック → ＋ → 新規 → ベースカラー → 割り当て → Tab → Cmd ＋ S

② 質感

メタリック・粗さ ― 金属か、つやか

ベースカラー色
メタリック0 ＝ 金属でない ⇄ 1 ＝ 金属（数値をクリックして入力 ／ 左右にドラッグ）

今日のまとめ

第8回のまとめ

  • モディファイア：元の形に効果を「かぶせる」。レンチ → モディファイアーを追加 → 生成
  • ミラー 左右対称（原点が中心）／ サブディビジョンサーフェス なめらか（＋ スムーズシェード）／ 配列 並べる（数・オフセット）
  • マテリアル：ベースカラー・メタリック・粗さ。右上の マテリアルプレビュー で見る
  • 一部だけ色を変える：Tab → 面を選ぶ → ＋ → 新規 → 割り当て
  • 課題：第7回のモノに モディファイア 1 つ以上 ＋ 色 2 色以上 → マテリアルプレビューのスクショを提出
