第10回 学習目標

前半は フラグ（true / false で状態を覚える箱） の使い方を3つの例で学びます。

  • Stage1：powerup フラグ ― キーを押している間だけ ON（Input.GetKey）

  • Stage4：パーティクルで噴水のエフェクトを出す（ps.Play()）
  • Stage5：爆発エフェクト＋音＋光を作る（おうよう）

使用プロジェクト：game1_h（Stage1〜5）。スクリプトは Cube1〜3.cs / Particle4.cs / Particle5.cs。各ステージは ★5分課題（1行書くだけ）で完成します。

Section 1

フラグ（true / false）の使い方

Stage1〜3 ― 状態を覚える箱を使い分ける

きほん

フラグ（flag）ってなに？

フラグ＝ 「オン」か「オフ」のどちらかを覚えておく箱です。
電気のスイッチや、チェックボックスの ☑／☐ をイメージしてください。

入るのは2つだけ

  • true（トゥルー）＝ オン・はい・ON
  • false（フォルス）＝ オフ・いいえ・OFF

身のまわりの例

  • 電気のスイッチ（ついてる／消えてる）
  • ゲーム：パワーアップ中？ 地面にいる？

C# では bool（ブール）という種類の箱に入れます。
true か false の2通りしか入らないのが特徴です。

きほん

フラグの使い方は3ステップ

1
用意する箱を作って、最初の状態を決める　→　bool powerup = false;（最初はオフ）
2
切りかえる条件が来たら ON／OFF を入れかえる　→　powerup = true;（オンにする）
3
使って分けるif で「今オンなら」と判断して処理を変える　→　if (powerup) { 高くジャンプ }
bool powerup = false; // ① 用意する（最初はオフ） powerup = true; // ② 切りかえる（オンにする） if (powerup) { // ③ 使って分ける（オンのときだけ） // ここはフラグが true のときだけ実行される }
ポイント：フラグは「今どうなっているか」を覚えておく係。覚えた状態を if で見て、処理を切りかえるために使います。
Stage1 / Cube1.cs

フラグ①　powerup（パワーアップ中か）

powerup という true / false の箱（フラグ）を用意。Aキーを押している間だけ ON にして、その間にスペースで跳ぶと高く跳べる。

public class Cube1 : MonoBehaviour { private Rigidbody cubeRB; public bool powerup = false; // パワーアップ中か void Start() { cubeRB = GetComponent<Rigidbody>(); } void Update() { powerup = Input.GetKey(KeyCode.A); // ★Aキー長押し中だけ ON if (Input.GetKeyDown(KeyCode.Space)) { if (powerup) cubeRB.AddForce(Vector3.up * 500); // 高く else cubeRB.AddForce(Vector3.up * 200); // ふつう } } }
★5分課題：powerup = Input.GetKey(KeyCode.A); と1行書く。GetKey は「押している間ずっと true」。Aを押しながらスペースで高く跳べたら成功！
Stage2 / Cube2.cs

フラグ②　isGround（地面にいるか）

isGround というフラグで「地面にいるか」を覚える。true のときだけ跳べるようにして、空中での連続ジャンプ（2段ジャンプ）を止める。

private bool isGround = true; // 地面にいるか void Update() { // 矢印キーで移動（→ ← ↑ ↓ を少しずつ） if (Input.GetKey(KeyCode.RightArrow)) transform.position += Vector3.right * 0.01f; if (Input.GetKeyDown(KeyCode.Space) && isGround) { cubeRB.AddForce(Vector3.up * 200); isGround = false; // ★跳んだら「地面にいない」 } } private void OnCollisionEnter(Collision collision) { isGround = true; // 着地したら戻す }
★5分課題：ジャンプ直後に isGround = false; と書く。着地（OnCollisionEnter）で true に戻るので、空中では跳べなくなる。
Stage3 / Cube3.cs

フラグ③　アイテムでフラグを ON にする

Stage1・2 のフラグを組み合わせ。Capsule（アイテム）にぶつかったその時だけ powerup を ON にして、アイテムを消す。

private void OnCollisionEnter(Collision collision) { isGround = true; // 着地（共通） if (collision.gameObject.CompareTag("Item")) { powerup = true; // ★アイテムでパワーアップ Destroy(collision.gameObject); // 取ったアイテムを消す } }

準備（Tag）

  • Capsule を選び、Inspector 上の Tag で「Item」を作って付ける

★5分課題

  • powerup = true; と1行書く → アイテムを取ると高く跳べる
Section 2

パーティクルシステム

Stage4 ― 「たくさんの小さなつぶ」で噴水を作る

イメージ

パーティクルシステムって何？

炎・煙・キラキラ・花火・水しぶき…
こういう「たくさんの小さなつぶ（粒子）」をまとめて出す Unity の部品です。

つぶ1個1個を手で動かすと…

  • 何百個もコードを書く必要がある
  • とても大変・重い

Particle System を使うと

  • 設定するだけで自動で出る
  • 数・色・速さ・形を数字で調整

Stage4 では空の箱に Particle System が付いていて、スペースキーで噴水のように打ち上がります。
数字を変えたら ▶ で再生 → スペースキーで変化を確かめよう。

Inspector ①

基本設定（いちばん上のブロック）

ParticleFountain を選ぶと Inspector に並ぶ、全体のルールです。

設定何をするかStage4の値
Duration何秒間つぶを出し続けるか5 秒
Loopingくり返しずっと出すかON
Start Lifetimeつぶが生まれて消えるまでの時間2 秒
Start Speed飛び出す速さ（大きいほど高く飛ぶ）6
Start Sizeつぶの大きさ0.3
Start Colorつぶの色白
Gravity Modifier重力の強さ（大きいほど早く落ちる）0.5

Play On Awake が OFF なので最初は止まっています → スペースキーで出す（=★5分課題）。
Inspector ②

Emission ― どれだけ出すか

設定何をするかStage4の値
Rate over Time1秒あたりに出るつぶの数50
  • 数を大きくする → もくもく・どばーっと濃くなる
  • 数を小さくする → ぱらぱら・さみしくなる

おまけ：Bursts（バースト） を使うと「一気にドン！」と出せます（花火・爆発向き → Stage5 で使用）。

Inspector ③

Shape ― どんな形・向きに出すか

つぶが飛び出す「出口の形」。Stage4 は Cone（円すい） を上向きにして噴水にしています。

設定何をするかStage4の値
Shape出口の形（Cone / Sphere / Box など）Cone
Angleコーンの広がり角度20 度
Radius出口の円の大きさ1
  • Sphere（球） → 全方向にぶわっと（爆発っぽい）
  • Box（箱） → 四角い範囲から（雨や雪っぽい）
Inspector ④

つぶの見た目（Renderer / マテリアル）

  • つぶ1個1個の「絵」を決めるところ
  • Stage4 は Unity標準の Default-Particle（ふわっと光る丸）を使用
  • 自分の画像（テクスチャ）を使ったマテリアルに変えれば、星・ハート・煙など好きな見た目にできる

まずは標準のままでOK。慣れてきたら自分で描いた画像を入れて、オリジナルのつぶを作ってみよう。

Stage4 / Particle4.cs

スペースキーで噴水を出す

using UnityEngine; public class Particle4 : MonoBehaviour { private ParticleSystem ps; // つぶつぶの部品を入れる箱 void Start() { ps = GetComponent<ParticleSystem>(); // 自分に付いた部品を取得 } void Update() { if (Input.GetKeyDown(KeyCode.Space)) { ps.Play(); // ★5分課題：この1行で噴水スタート！ } } }
★5分課題：「★ここに書く」に ps.Play(); と1行書くだけ。▶ → スペースキーでつぶが噴き出せば成功！
やってみよう

いじって楽しい順 おすすめ3つ

1
Start Color … 色を変える青・赤・虹色にしてみよう
2
Start Speed … 噴き出す速さ大きくして高く飛ばそう
3
Emission > Rate over Time … つぶの数増やして派手に！

数字を変える → ▶ で再生 → スペースキー、をくり返して「自分だけの噴水」を作ってみよう。

発展

もっと派手にする追加モジュール

Inspector の各項目の左の □ にチェックを入れるとONになり、効果を足せます。

モジュール何ができるか
Color over Lifetime時間とともに色を変える（赤→黄→消える。炎・花火向き）
Size over Lifetime時間とともに大きさを変える（だんだん小さく消える）
Velocity over Lifetime飛んでいる途中で動きを足す（風で流す、など）
Noiseゆらゆら不規則に揺らす（煙・炎のゆらめき）
最初は OFF。慣れてきたら1つずつ ON にして遊ぶのがおすすめ。

新しい用語

爆発で出てくる新しい用語

  • Burst（バースト）：Time（いつ）と Count（何個）を指定して一気にドンと出す。Count を増やすと迫力アップ
  • Shape = Sphere：球状＝全方向に飛び出すので「丸く爆発」する
  • Color over Lifetime：だんだん透明にして、煙のように自然に消す
  • Trails（軌跡）：つぶの後ろに尾を引いて、花火のように見せる
  • Light（ライト）：爆発の瞬間だけ周りをパッと明るく照らす（プログラムで制御）
Stage5 / Particle5.cs

爆発＋音＋光をまとめて再生

private ParticleSystem ps; // つぶつぶ private AudioSource explosionSound; // 爆発音 private Light flashLight; // ピカッと光るライト void Start() { ps = GetComponent<ParticleSystem>(); explosionSound = GetComponent<AudioSource>(); flashLight = GetComponent<Light>(); } void Update() { if (Input.GetKeyDown(KeyCode.Space)) { ps.Play(); // ★爆発させる explosionSound.Play(); // ドンッ！と音 flashLight.intensity = 8f; // パッと光る } // 毎フレーム少しずつ暗く → ピカッと光って消える flashLight.intensity = Mathf.Lerp(flashLight.intensity, 0f, Time.deltaTime * 8f); }
サウンド

爆発音（サウンド）のしくみ

  • explosion.wav（爆発音）が Assets/explosion.wav に入っている
  • Explosion に付いた AudioSource にこの音が入っている
  • Play On Awake = OFF なので、スクリプトの explosionSound.Play(); で鳴らす

音量を変えたい

  • AudioSource → Volume（0〜1）を変える

別の音にしたい

  • 好きな音ファイルを Assets に入れ、AudioClip にドラッグして差し替え

まとめ

今日のまとめ

  • フラグ＝ true / false で状態を覚える箱。「今どうなっているか」を判断に使う
  • powerup（長押しで ON）・isGround（接地で ON）など、目的に合わせてフラグを使い分ける

  • Looping・Shape・Burst を変えると、噴水も爆発も作れる
