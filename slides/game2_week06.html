音に反応させる

音の波形をキーフレームに焼き込む（サウンドをベイク）→ 大きさや Geometry Nodes を音で動かす。リアルタイムは TouchDesigner に素材を渡す

検索ワード：Blender VJ loop ／ Blender audio reactive ／ Blender TouchDesigner ／ 日本語なら「Blender Infinite Loop VJ」

Blender と音楽

VJ ソフト ― Blender の映像を、音に合わせて流す

TouchDesigner ↗ ノードをつないで、映像・音・センサーをリアルタイムに処理。インスタレーションやライブ演出に Mac／Windows ・ 無料版あり（非商用・1280×1280 まで）
VDMX ↗ 画面を自由にレイアウトして、ループ映像の切り替えやエフェクトを操作 Mac 専用 ・ 体験版あり（保存以外はすべて使える）
Resolume ↗ クリップを並べて、押すだけで切り替え。Avenue＝VJ、Arena＝プロジェクションマッピングも Mac／Windows ・ 体験版あり（ロゴとロボット音声が入る）

流れ：Blender で数秒のループ映像を書き出す → VJ ソフトに読み込む → 音や MIDI コントローラーで切り替える

③ やってみよう

「丸いす」を作って、保存する ― ツールバーでも、ショートカットでも

ツールバー・メニューでショートカットで
1 立方体を消すオブジェクト → 削除X → 削除
2 座面を出す追加 → メッシュ → 円柱Shift ＋ A → メッシュ → 円柱
3 小さく・平たくスケール ツール：白い輪をドラッグ → 青い箱をドラッグS → 指 → クリック、S → Z → 指 → クリック
4 腰の高さへ移動 ツール：青い矢印を上へG → Z → 指 → クリック
5 脚を出して細く・長く・置く追加 → 円柱 → スケール（白い輪・青い箱）→ 移動（青・赤の矢印）Shift ＋ A → 円柱 → S、S → Z → G → Z、G → X
6 脚を少し開く回転 ツール：緑の輪をドラッグR → Y → 指 → クリック
7 回転の中心を 3D カーソル（真ん中）にヘッダーの ピボットポイント → 3D カーソル. キー → 3D カーソル
8 脚を 3 本に（2 回）オブジェクト → オブジェクトを複製 → 右クリック → 回転 の青い輪で 1／3 周Shift ＋ D → ⏎ → R → Z → 指 → クリック
9 保存ファイル → 保存Cmd ＋ S

どちらでも同じ結果。数値は打たず目で決める。ツールバーは 移動（十字）・回転（輪）・スケール（箱）。やりすぎたら Cmd ＋ Z

今日のまとめ

第6回のまとめ

  • 視点：2本指で回す・ギズモ・1／3／7・Home
  • 足す：Shift ＋ A → メッシュ、消す：X
  • 動かす：G・R・S → 軸 X／Y／Z → 数値 → ⏎。戻すは Cmd ＋ Z
  • 保存：Cmd ＋ S（.blend、名前は英数字）
  • Tab で オブジェクトモード ⇄ 編集モード（点・線・面をいじる）→ 次回

次回：第7回 編集モード（Tab）― 点・線・面を押し出し・ループカットで作り込む。今日の .blend は消さない。
